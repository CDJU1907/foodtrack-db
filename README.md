# foodtrack-db

## Descripción del proyecto

Base de datos relacional para FoodTrack, una plataforma para gestionar la operación de foodtrucks en distintos puntos de una ciudad.

El sistema contempla información sobre los foodtrucks, los productos que ofrece cada uno, los pedidos que reciben, el detalle de qué productos incluye cada pedido, y las ubicaciones donde operan.

Este repositorio está desarrollado como parte del Módulo 2 de la carrera de Data Science en Henry, e implementa el modelo en Microsoft SQL Server, gestionado con DBeaver como cliente y versionado con Git y GitHub.

## Estructura del repositorio

- `/scripts/`: scripts SQL de creación del esquema
- `/data/`: archivos CSV utilizados como fuente de datos
